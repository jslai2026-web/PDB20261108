Share & settings

Share the app

The app is one HTML file with no data inside. Send it to colleagues: each person opens it in their own browser, sets their own passcode and keeps their own data in their own browser. Nothing is stored on a server.

Share projects with a colleague

Creates an encrypted file protected by a passphrase you choose. Send the file, and give the passphrase separately.

Word report

AI key (standalone file only)

Inside Claude the AI works without a key. In the standalone file the AI requests go straight from your browser to Anthropic using your own key, kept encrypted with your passcode. Use a key with a spending limit.

Erase everything in this browser

Save projects to a folder

Writes your projects to a folder on this computer. Where your browser allows it you pick the folder; otherwise one file is downloaded for you to move into your desktop folder. Pick or create a subfolder (for example Desktop/ES-Projects), because browsers do not allow Desktop itself.

Unticked, the folder gets readable files: one folder per project with project.json and summary.txt, plus all-projects.json. Anyone with the folder can read them.
