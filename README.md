# ES Project Dashboard

Engineering Services project dashboard. One HTML file (`index.html`), front end only:
no back end, no server, no database. Open it in a browser.

- Data is saved only in the user's browser, encrypted with the user's passcode (8+ characters).
- Share the app by sending the file. Share projects with an encrypted, passphrase-protected file.
- Export project reports and generated documents to Word (.docx).
- AI features: inside Claude they use Claude. In the standalone file, add your own Anthropic API key
  under "Share & settings" (kept encrypted in the browser, calls go straight to Anthropic).
- Keep the GitHub repository private.
